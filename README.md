# Hotel Management System

A Java Swing and MySQL based Hotel Management System that simplifies hotel operations with features like User Login, Guest Management, Room Management, Room Booking, Billing, Check-In/Check-Out, Booking Search, and JDBC database integration.

## Features
- User Login
- Guest Management
- Room Management
- Room Booking
- Billing & Invoice Generation
- Check-In / Check-Out
- Booking Search
- MySQL Database
- Java Swing GUI

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL

## Modules
- Login Module
- Guest Management
- Room Management
- Booking Management
- Billing Management
- Check-In / Check-Out
